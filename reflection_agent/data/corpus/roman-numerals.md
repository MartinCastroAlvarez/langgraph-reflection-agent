# Roman numerals

- Roman numeral symbols: I = 1, V = 5, X = 10, L = 50, C = 100, D = 500, M = 1000.
- Roman numerals are read left to right and the symbol values are added.
- Roman subtractive notation: a smaller symbol placed before a larger one is subtracted, as in IV = 4, IX = 9, XL = 40, XC = 90, CD = 400 and CM = 900.
- Roman parsing rule: when a symbol's value is less than the value of the symbol after it, subtract it instead of adding it.
- Roman example: MCMXCIV = 1000 + 900 + 90 + 4 = 1994.
- Roman input handling: lowercase input can be accepted by upper-casing it first; an unknown symbol is an error.
